# X-COM V1.0 串口工作台

X-COM 是一款基于 Qt 6 的多会话串口调试工具，支持串口与回环会话、收发数据、命令行批量发送、数据解析和插件扩展。内置插件还提供校验计算、字符串与十六进制转换，以及 TCP/UDP 网络调试功能。

## 快速开始

### 使用 Windows Release 包

1. 下载并解压 `X-COM-V1.0-win64.zip`。
2. 保持解压目录中的程序、Qt 运行库和 `plugins` 文件夹在一起，不要只复制 `X-COM.exe`。
3. 双击 `X-COM.exe` 启动。
4. 点击“新建会话”，在“串口配置”中选择端口并设置参数，然后点击“打开”。

没有可用串口时，端口列表会提供“回环测试”，可不连接硬件地体验发送与接收。连接真实串口时，请先确认端口没有被其他程序占用，并按设备要求选择波特率、数据位、停止位、校验位和流控。

## 串口会话与控制台

每个会话有独立的串口参数、接收区、发送区和命令行。可同时创建多个会话；同一个真实串口不能被多个会话同时占用。

新建会话后会打开串口配置页。会话名称默认采用串口名；回环会话默认名为“回环测试”。修改参数后点击“应用”，首次打开会话时点击“打开”。

控制台接收区常用操作：

- **HEX 接收**：将收到的字节按十六进制显示；关闭时按文本显示。
- **时间戳、自动滚动、暂停显示**：调整接收区的显示方式。暂停显示不会替代设备侧的数据处理。
- **清空、保存**：清除接收显示或将接收数据保存到文件。
- **HEX 发送**：把输入内容按十六进制字节解析后发送，例如 `AA 55 01`。
- **新行**：在文本发送内容后追加换行符。
- **DTR、RTS**：切换串口控制信号。设备是否使用这些信号取决于硬件接线和驱动设置。
- **发送文件**：选择文件并发送原始字节；发送过程中可停止。
- **快速发送**：在数据输入框按 `Ctrl+Enter`。

输入框右下角的垃圾桶图标用于清空待发送内容。

## 右侧命令行

命令行用于保存并逐行发送常用数据指令。点击“＋ 行”添加一行；也可以在控制台输入框中按换行组织多条内容，再点“提取内容”填入命令行。

每行包含勾选框、序号、数据输入框、发送按钮、延迟、HEX、换行和删除按钮：

- 勾选多行后点“运行”，按行发送选中项；“全选”可批量勾选或取消。
- 点某一行的“发送”只发送该行，并会自动勾选该行。
- 延迟单位为毫秒，`0` 表示立即发送；HEX 行按十六进制字节解析。
- “循环”设置整组勾选行的运行次数；点“停止”中断批量运行。
- “清空数据”清除所有行内容；“提取内容”按输入框的行拆分填充，已有行会保留，多出的内容会新增行。

## 串口命令行、命令解析与面板

会话顶部的按钮可以分别显示或隐藏“控制台”“命令行”“串口配置”“串口命令行”和“命令解析”。这些按钮各自控制对应区域。

- **串口命令行**：在底部面板中交互发送内容，支持历史记录和 HEX 发送模式。
- **命令解析**：查看接收数据的解析结果，并使用解析器提供的分帧设置和导出功能。
- **浮动会话**：拖动会话标签页到窗口外，可将整个会话窗口浮动；点击浮动窗口标题栏右上角的关闭按钮可吸附回主窗口。主窗口最小化时，浮动会话会保持可见；恢复主窗口后会还原用户的置顶设置。
- **固定在最前**：将浮动窗口保持在其他普通窗口之上。该设置可通过会话顶部的按钮切换。

## 内置工具插件

从左侧活动栏打开工具；插件状态可在“插件”视图中查看。

- **校验计算器**：输入十六进制字节，计算 CRC16/Modbus、CRC16/CCITT、SUM8 或 XOR8。
- **字符串与十六进制转换**：在 UTF-8 文本与十六进制字节之间转换，并复制结果。
- **TCP/UDP 服务**：打开 TCP/UDP 工具页。TCP 支持客户端连接和服务端监听；UDP 支持绑定本地端口及收发数据。文本或 HEX 数据可用于发送，连接状态和收发信息会显示在日志区域。
- **会话资源管理器**：查看会话列表，双击会话打开控制台，或通过右键菜单操作会话。

## 从源码构建

### 环境

- CMake 3.21 或更新版本
- C++17 编译器
- Qt 6.5 或更新版本，包含 Core、Gui、Widgets、SerialPort；内置 TCP/UDP 插件还需要 Network
- Windows x64 Release 包由 Qt 的 `windeployqt` 部署运行库

以下示例使用 Windows、Ninja 和 Qt 6.7.3 MinGW x64。请将 Qt 路径替换为本机安装位置，并确保 Qt 与编译器套件匹配：

```powershell
cmake -S . -B build-v1 -G Ninja `
  -DCMAKE_BUILD_TYPE=Release `
  -DCMAKE_PREFIX_PATH="D:/Qt/6.7.3/mingw_64" `
  -DXCOM_BUILD_PLUGINS=ON `
  -DXCOM_BUILD_TESTS=OFF
cmake --build build-v1 --parallel
```

可运行程序位于 `build-v1/bin/X-COM.exe`，插件位于同一目录下的 `plugins/` 文件夹。Windows 构建会在可找到 `windeployqt` 时自动部署 Qt 运行库。
